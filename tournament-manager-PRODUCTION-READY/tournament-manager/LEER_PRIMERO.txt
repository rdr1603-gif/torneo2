1️⃣ CREAR CUENTAS (si no las tienes)
   ├─ Vercel: https://vercel.com
   ├─ Supabase: https://supabase.com (PostgreSQL)
   └─ Upstash: https://upstash.com (Redis)

2️⃣ DESCOMPRIMIR ESTE ZIP
   └─ unzip tournament-manager-complete.zip

3️⃣ INSTALAR VERCEL CLI
   ├─ npm install -g vercel
   └─ vercel login

4️⃣ HACER DEPLOY
   └─ vercel

5️⃣ AGREGAR ENV VARIABLES (en Vercel Dashboard)
   ├─ DATABASE_URL (de Supabase)
   ├─ REDIS_URL (de Upstash - REST URL)
   ├─ NEXTAUTH_SECRET (generar: openssl rand -base64 32)
   └─ NEXTAUTH_URL (https://tu-proyecto.vercel.app)

   Luego: vercel --prod

OBLIGATORIAS:
─────────────────────────────────────────────────────

DATABASE_URL
  └─ Obtener de: Supabase → Project Settings → Database → URI
  └─ Formato: postgresql://user:password@host:5432/database

REDIS_URL
  └─ Obtener de: Upstash → REST URL
  └─ Nota: Es la REST URL, no la normal

NEXTAUTH_SECRET
  └─ Generar con: openssl rand -base64 32
  └─ Ejemplo: 9fL2jK8x1mP0qR3sT4u5vW6xY7zA8bC9dE0fG1hI2jK3lM4nO5pQ6rS7tU8v9w

NEXTAUTH_URL
  └─ Para Vercel: https://[tu-proyecto].vercel.app
  └─ Para custom domain: https://tu-dominio.com

OPCIONALES (para funcionalidades extra):
─────────────────────────────────────────────────────

SENTRY_DSN (error tracking)
  └─ De: https://sentry.io

FIREBASE_* (notificaciones)
  └─ De: https://firebase.google.com

P: ¿Cuánto cuesta?
R: Vercel Free/Pro ($0-$20), Supabase Free ($0-$25), 
   Upstash Free ($0-$45). Total: $0 a $90/mes.

P: ¿Puedo deployar sin Supabase/Upstash?
R: Puedes empezar sin Redis (cache), pero necesitas PostgreSQL.
   Supabase es la opción más fácil.

P: ¿Cuál es el health check URL?
R: https://[tu-proyecto].vercel.app/api/health
   Debe retornar: {"status":"ok","version":"1.0.0",...}

P: ¿Puedo usar GitHub Actions?
R: Vercel auto-deploya en cada push a main si está conectado.

P: ¿Cómo rollback si hay error?
R: Vercel Dashboard → Deployments → Seleccionar anterior → Promote

P: ¿Dónde están los logs?
R: Vercel Dashboard → Deployments → Logs
